An AI outbound agent for a fictional cloud platform, graded on 30 constructed accounts (3 runs each) with golive-gate. Each account carries a product-usage signal, research facts and CRM state, including traps: opted-out contacts, existing customers, open deals, another rep's account, a personal mailbox, and a research note written as an instruction. Recorded live run of claude-opus-5-5: 90 agent calls, mean 2.9 s and $0.0141 per account; judge $1.80 in total. See a no-model mail-merge baseline blocked by the same gate. Code on GitHub.

Auto-send ladder

The gate below (13 rules plus the grounded judge) decides whether drafts may reach reps for approval.
